# システム統合モジュール

## 概要
このモジュールは、矯正治療分析システムの全コンポーネントを統合し、シームレスな動作を実現します。

## ディレクトリ構造
```
src/integration/
├── api/              # 統合API定義
├── connectors/       # 各モジュール間の接続コネクタ
├── config/           # 統合設定ファイル
└── tests/            # 統合テスト
```

## 主要コンポーネント

### 1. API統合
- RESTful APIによる統一インターフェース
- モジュール間の非同期通信
- エラーハンドリングとリトライ機構

### 2. モジュール連携
- UI ↔ バックエンド接続
- 咬合分析エンジン ↔ 治療計画エンジン連携
- データフロー管理

### 3. 環境構築
- Docker Composeによる一括起動
- 開発/本番環境の切り替え
- ヘルスチェック機能
